# Garnet release notes

## v1.0.0 - Sep 2026

Release of the Garnet model to accompany the paper. The model is unchanged since v0.1.0. More validation scripts, optional template XML and PDB file writing, and re-use of identical atom types have been added.

## v0.1.0 - Feb 2026

Initial release of the `garnetff` Python package for assigning force field parameters using the Garnet model. Training code is also available.
